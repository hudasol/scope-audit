# Data labels 🍋

Every figure, table and statement of results in this repository names one of the labels below.

| Label | Meaning |
| --- | --- |
| BORROWED | Real data collected by others. Caltech Camera Traps images and annotations, hosted by LILA BC under a permissive data licence. |
| PUBLISHED | A detector output or figure released by its authors. The MegaDetector results for the benchmark come from the LILA BC release and were not recomputed here. |
| SYNTHETIC | Generated by code in this repository. Used for calibration against a known truth and for placeholder deployment coordinates. |

Nothing in this repository is labelled as collected in the United Arab Emirates, because no such data were used.

## Files

- data/working_set contains the feature table for the benchmark working set (BORROWED, with PUBLISHED detector confidences).
- data/demo contains 60 reduced demo images (BORROWED), the demo events table, and the registry of deployments (SYNTHETIC coordinates).
- data/reference contains the GBIF candidate species list (candidate only) and the Camtrap DP schemas (PUBLISHED by the standard authors).
- results contains experiment outputs. Each file carries its data label in its header.
