# Ninety day pilot plan 🌿

## Days 1 to 30: set up

- Agree with the Ministry which camera deployments, detector version and review team take part.
- Install the system on infrastructure approved by the Ministry. Load deployment registry data with real coordinates and dates.
- Run the integrity checks on a historical batch and correct metadata with the field teams.

## Days 31 to 60: first audits

- Run the detector on a historical batch and draw the review sample for the chosen threshold and budget.
- Train reviewers on the three outcomes: animal, empty and unresolved. Measure how often two reviewers disagree on a shared subset.
- Report the false omission rate with its interval and the sensitivity bounds.

## Days 61 to 90: decision

- Compare designs on the pilot batch using the same code as the benchmark experiments, and report any miss against the predictions made here.
- Decide with the Ministry whether the threshold can be raised, whether the review budget is acceptable, and what must change in the field.
- Export approved observations as a Camtrap DP package and test its use by a partner system.

## Exit criteria

The pilot succeeds when the interval is narrow enough to support a threshold decision, reviewers agree sufficiently, and the Ministry accepts the audit trail. The pilot fails openly when any of these is not met, and the report says so.
