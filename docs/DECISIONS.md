# Decisions

Decisions taken during the build, with the reason for each.

1. Benchmark choice. Caltech Camera Traps (CDLA permissive, labels with sequence identifiers, locations and timestamps) is the primary benchmark because published MegaDetector results exist and it has about 70 percent empty images, so a negative pool exists.
2. Known leakage. The data page and the detector documentation state that Caltech Camera Traps was used to train earlier MegaDetector versions. Absolute error rates on it are treated as optimistic. This was recorded in docs/PRIOR_ART.md before any experiment.
3. Desert Lion Conservation Camera Traps was checked and not used for experiment B. It is arid but has no images labelled empty, so the truth for blank predictions cannot be estimated without selection bias.
4. Detector results. The published MegaDetector v5a results file from LILA is ingested in place of running inference. No heavy inference is run in this build.
5. Event definition. Events are the sequences given by the dataset sequence identifier. An event is AI negative at threshold T only if every frame has no animal detection at confidence T or higher.
6. Stress regime. By the pre registered rule, applied to experiment A on the full benchmark labels, the stress threshold is 0.6 (the smallest threshold in the sweep at which event FOR reaches 2 percent). It was fixed from experiment A before experiment B was run.
7. Working set for experiment B. 8,000 events are drawn uniformly at random, with a fixed seed, from all benchmark events. Image features are computed on one frame per event (the middle frame by frame number) to limit download volume. Images are downloaded one at a time, reduced, measured and discarded. Only features are stored.
8. Detector result storage. The published results file stores detections from confidence 0.01 upward, so the "none" confidence stratum means no detection at or above 0.01.
9. Post hoc interval. The first run of experiment C (committed as results/experiment_c.json) showed that the three registered stratified intervals miss the 93 to 97 percent target for disproportionate allocation: the plug in Wald and bootstrap intervals undercover, and the smoothed variance interval is far too wide. A Bayesian beta binomial interval with a Jeffreys prior (which handles strata with no hits and the finite population correction exactly) was therefore added after seeing those results. It is labelled exploratory, is not part of predictions P1 to P8, and is reported separately from the registered intervals.
10. Headline interval. After the final calibration run, no interval reached 93 to 97 percent coverage in every setting (see results/RESULTS.md). The smoothed variance Wald interval is conservative but rarely falls much below the target on the benchmark working set, the beta binomial interval is closer to the target on the benchmark but weak on rare synthetic cases, and the plug in Wald and bootstrap intervals undercover. The application and reports therefore show the smoothed variance interval first for stratified designs, and the Wilson interval for simple random samples. This choice was made after seeing the results and is recorded as post hoc. Criterion S2 is scored as written and is reported as missed.
11. Placeholder deployment registry. The Camtrap DP deployments table requires latitude, longitude and deployment dates. The benchmark data are not from the Emirates and its locations are anonymised, so the demo registry holds SYNTHETIC coordinates derived from the location number and says so in every row and in the package description. A real registry must replace it before any real export.
12. Reviewer in the experiments. The reviewer is an oracle that reads benchmark labels. The unresolved category is exercised by sensitivity bounds on synthetic unresolved shares, not by real reviewer behaviour.
13. Scoring of ambiguous predictions. Where a prediction sentence left a choice open, scripts/evaluate_predictions.py applies one reading to every cell: budgets 100 to 400 for P2 to P4, budgets 200 and above for P5 and P7, budgets 400 and above for P6 and S2, and M2 in the stress regime for the interval clauses. The reading is written next to each test.
