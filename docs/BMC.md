# Business model canvas 🌸

| Block | Content |
| --- | --- |
| Customer segments | Environment ministries and agencies, protected area authorities, research institutes and conservation programmes that run camera traps. |
| Value proposition | A defensible number for what an automated filter missed, a smaller review burden, and a clean audit trail from machine suggestion to approved record. |
| Channels | Direct engagement through government programmes, open source release, and partnerships with biodiversity data platforms. |
| Customer relationships | Pilot support, reviewer training and a shared method that others can inspect. |
| Revenue streams | Support and hosting agreements, pilot fees and training. No revenue figure is claimed here. |
| Key resources | The statistical engine, the review log, the export module and the documentation. |
| Key activities | Calibration studies, pilot delivery, maintenance and standards alignment. |
| Key partners | Detector authors, biodiversity data standards groups, and local field teams. |
| Cost structure | Engineering, hosting and reviewer time during pilots. |

Nothing in this canvas rests on a measured market size. Any size would have to be added with a source.
